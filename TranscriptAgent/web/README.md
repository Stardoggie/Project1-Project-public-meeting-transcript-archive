# Web front end

One page, `index.html`, for chatting with the agent, answering its confirmations, uploading MP3/WAV recordings and
reading or downloading full transcripts. It runs in two ways.

## Hosted (CloudFront)
`agentcore deploy` publishes it. The stack outputs `SiteUrl` (the CloudFront address).

- **No sign-in:** anyone with the address can use the agent, including changing and deleting archive records and
  uploading recordings. Keep the address private.
- **API:** CloudFront sends `/api/*` to a Lambda (`agentcore/cdk/lambda/api/index.ts`) through origin access control. The Lambda
  calls the runtime. Each conversation is kept apart by its session id, a random value the browser makes.
- **Uploads** go from the browser straight to the presigned S3 link the agent hands out. The recordings bucket
  allows `PUT` from the site's address only.
- `config.json` (which tells the page it's hosted) is generated by the deploy. It isn't in this folder.

## Local
With `agentcore dev` running in `TranscriptAgent/`:
```
python server.py
```
Then open http://127.0.0.1:8501. There's no sign-in: the server only listens on this computer, and it uploads
recordings for the page. To use the deployed runtime with your own AWS credentials instead, run
`uv run --project ../app/agent python server.py --runtime-arn <runtime ARN>` (`agentcore status` shows the ARN).
